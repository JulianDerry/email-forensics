A specialist portfolio focused on the forensic examination and authentication of email evidence, including phishing investigations, message headers, routing information and authentication controls.

- Email Header Analysis
- Delivery Path Reconstruction

- Email Routing and Metadata Examination

### 🔐 Authentication Analysis

- SPF
- DKIM
- DMARC
- Domain alignment
- Authentication-Results interpretation
- Header consistency analysis

### 🛠️ Tool Development Roadmap

- Email Header / Infrastructure Analyzer

## Current Case Study

### Phishing Email Investigation

The repository includes a documented phishing email investigation with evidence handling, hashing, delivery-path analysis, SPF, DKIM, DMARC, header consistency and embedded URL analysis.

## Investigation Standard

The analysis distinguishes between authentication results, mail infrastructure evidence, message metadata and conclusions that can actually be supported by the available evidence.

## Disclaimer

Investigations in this repository are conducted on training datasets, lab environments, or authorized evidence sources for educational and professional portfolio purposes. Portfolio material does not represent confidential client evidence.
