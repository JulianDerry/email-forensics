# Email Forensics

A digital forensics repository focused on the acquisition, preservation, examination, and analysis of email evidence.

## Areas of Analysis

- Email Header Analysis
- SPF, DKIM & DMARC Authentication
- Phishing Email Investigation
- Sender & Domain Analysis
- Email Routing & Metadata
- URL & Attachment Analysis
- Email Forensics Tool Development
